# Attributes
## Primary Attributes
Determined at character creation, these attributes represent one's physical and mental characteristics, as well as being used to determine certain [[Characters#Secondary Attributes|Secondary Attributes]] and to build dice pools for [[Attribute Checks]].
- **VIT** - Vitality: Represents one's endurance and toughness, used to determine Max HP
- **STR** - Strength: One's physical strength, used for most melee attacks
- **DEX** - Dexterity: One's agility, used for ranged attacks and some melee attacks
- **INT** - Intelligence: Represents one's intelligence, reasoning and education
- **SEN** - Senses: One's perception and attention to details
- **ART** - Arts Assimilation: Represents one's ability to control originium, used by arts attacks
## Secondary Attributes
These attributes provide additional parameters for a character's combat capabilities, and are determined by various means.
- **Max HP** - Maximum Hit Points: max size of a character's health tracker
- **EVA** - Evasion: Represents one's ability to dodge or block attacks, used as difficulty for attack rolls against the character
- **MOV** - Move: How many squares the character can move each turn
- **Block** - Block Count: How many enemies can the character block at a time
- **DEF** - Defense: Defensive attribute against physical damage
- **RES** - Resistance: Defensive attribute against arts damage
- **ASPD** - Attack Speed: How many attack actions can the character use each turn
- **INI** - Initiative: Determines the size of the pool for the [[Combat#Initiative|Initiative]] roll
# Traits
Features of a character granted by their race and branch. Cannot be chosen in other way than choosing race and branch themselves.
# Talents
Additional character features that can be chosen as the character progresses. Access to talents is given by classes and branches.
# Triggers
Triggers represent a character's specialized training or innate ability at a determinate task. During an [[Attribute Checks |Attribute Check]], up to one trigger matching the action that is being attempted can be used to increase the dice pool size by its value.
# Creation
1. Choose **Race**. Racial Traits usually give one (or a choice of one) Primary Attribute, as well as optionally giving bonuses to EVA, MOV, DEF or RES and other unique traits.
2. Choose **Origin**. Select (value) **triggers** between the chosen origin's list.
3. Choose **Class**. Class traits defines base Max HP, Block and ASPD as well as providing a weapon proficiency and determining triggers per level.
4. Choose **Branch**. Branch traits can modify Secondary Attributes, grant additional weapon proficiencies and optionally other unique effects.

7. Choose **Triggers** up to the class value of triggers per level.
8. Choose (value/1?) **Talents** from class, branch and general? lists.
9. Choose (value) **Skills** from the class and branch lists.
