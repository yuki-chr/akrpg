# Overview
- **Caster** *(deal arts damage)*
	- Core Caster *(can choose an arts school and gain bonuses using skills of that school)*
	- Mech-Accord Caster *(drone attacks, damage boost on same target)*
	- Mystic Caster *(can store mystic dice instead of attacking to use them later)*
	- Chain Caster? *(attacks bounce. maybe just weapon type?)*
	- Shaper Caster? *(spawn summons on defeated enemies)*
- **Defender** *(tank enemies)*
	- Guardian Defender *(nothing special, but maybe gets access to some healing skills)*
	- Fortress Defender *(long range aoe damage)*
	- Sentry Defender *(medium range single target damage)*
- **Guard** *(fight melee)*
	- Dreadnought/Centurion Guard *(block 1, basic guard)*
	- Reaper Guard? *(gains dice from hitting enemies to spend for things?)*
	- Instructor Guard *(deals more damage when not blocking, can use reach weapons)*
- **Medic** *(heal)*
	- Medic Medic
	- Incantation Medic *(can use caster weapons, heals passively when hitting enemies)*
- **Sniper** *(deal ranged phys damage)*
	- Marksman Sniper *(can choose a weapon proficiency between ranged weapon types)*
	- Deadeye Sniper? *(stealth, long range ST damage, maybe ranged sneak attacks?)*
	- Besieger Sniper? *(turret mode heavy damage?)*
- **Specialist** *(do weird stuff and confuse allies and enemies alike)*
	- Executor Specialist *(stealth, sneak attack, mobility skills and burst damage)*
	- Trapmaster Specialist *(places traps duh)*
	- Dollkeeper Specialist? *(puppet character)*
	- Skyranger Specialist? *(flies???)*
- **Supporter** *(buffs, debuffs, backup healing, CCs, cleanses)*
	- Hexer/Ritualist Supporter *(debuffs, slows)*
	- Summoner Supporter *(can use summons)*
	- Bard Supporter *(buffs and backup healing)*
	- Artificer Supporter *(uses melee weapons, can deploy support devices)*
- **Vanguard** *(high initiative, can generate morale)*
	- Charger Vanguard *(melee, generates morale with takedowns)*
	- Flagbearer Vanguard *(has a flag they can use to provide buffs to allies and generate morale)*
	- Tactician Vanguard *(can summon a minion and use it to support allies)*
	- Agent Vanguard *(ranged, has access to stealth, stat stealing and marks)*
